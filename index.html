What to Run Where
🧠
Frontier Models (Claude/GPT)
Complex reasoning, agentic decisions, multi-step tasks. No GPU needed — API calls only.
⚡
Local Ollama (Mac mini node)
Fast, cheap classification, drafting, summarization. Runs 24/7, no per-minute cost.
🏋️
RunPod Pod (on-demand)
Training runs, fine-tuning, large model inference. Spin up → use → destroy. Pay per minute.
🚀
RunPod Serverless
Deploy a trained model endpoint. Scales to zero. Pay per request, not per hour.
Fine-Tuning Pipeline
1
Prepare Training Data
Format as JSONL — prompt/response pairs. ~500 examples for a focused fine-tune. Upload to R2 or DO Spaces.
2
Pick a Base Model
Download from Hugging Face. Llama-3.2-7B or Mistral-7B are ideal starting points. Free open weights.
3
Spin Up RunPod A100 Pod
Use Unsloth template. ~$1.50/hr. Training a 7B model on 500 examples = 15–30 min = ~$0.75.
4
Run Fine-Tune with Unsloth + LoRA
LoRA = parameter-efficient fine-tuning. Saves a ~100MB adapter file, not the full 7B model.
5
Save Adapter → Deploy
Push adapter to Hugging Face or R2. Merge with base model. Deploy as RunPod Serverless endpoint.
6
Update OpenClaw Model Config
Point the new endpoint URL at your RunPod Serverless deployment. OpenClaw routes to it automatically.
